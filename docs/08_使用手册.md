# 链眼 · 使用手册

链眼是一个「面向产业链的可溯源投研智能体」：在受控数据环境中，把一份上市公司年报，从「数据提取 → 人工复核 → 财务诊断 → 情景研究 → 智能研究 → 报告」走成一条可追溯、可复现的闭环。首版案例为宁德时代 2025 年度动力电池业务。

## 一、快速启动

后端（另开一个终端）：

```bash
python tools/start_backend.py
```

前端：

```bash
cd frontend
npm ci
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。后端在 `http://127.0.0.1:8000`，接口文档 `/docs`。

**DeepSeek 密钥**（用于「研究任务」的智能生成）：在 `.env` 里配置 `DEEPSEEK_API_KEY`，或用系统环境变量 `setx DEEPSEEK_API_KEY "sk-..."`。未配置时，研究任务会提示「模型不可用」，其余功能不受影响。

## 二、使用流程（四个标签页）

### 1. 数据复核 —— 建立可信基线

- 上传年报 PDF（≤30 MiB、≤500 页、文本型），后端自动提取候选事实。
- 表格展示「原值 / 规范值 / 单位 / 期间 / 业务 / 状态」，缺失与冲突用彩色徽标区分。
- 点击任意一行进入「人工复核」，左侧改值、右侧同屏显示原文证据（PDF 页码 + 摘录 + 坐标 + SHA256），确认后才标记「已复核」。

### 2. 财务诊断 —— 2024 vs 2025 对比

- 切换集团 / 动力 / 储能，看经营指标（收入、成本、毛利率、归母净利润、现金流）与资产负债指标（存货、应收、资产）的两年对比。
- 底部「核查提示」明确：存货/应收增长是核查信号、非结论；扣非差额 ≠ 非经常性损益。

### 3. 情景研究 —— 条件情景计算

- 选择业务与基线年度，设置三个研究假设：成本暴露 s、价格冲击 x、客户传导 k，确认后运行。
- 展示基线 vs 情景的「收入 / 成本 / 毛利润 / 毛利率 + 变化」，并可展开计算溯源。
- 「27 格点敏感性」一键跑 s×x×k 组合，用热力表看毛利率随假设变化的敏感性。

### 4. 研究任务 —— 智能体闭环

- 输入一条研究问题（如「分析 2025 年动力电池业务收入和毛利变化」），选择业务与模式，创建任务。
- 后端自动编排：数据提取 → 基线校验 → 财务计算 → 受控模型调用 → 引用核验 → 报告生成。
- 页面实时展示状态、事件时间线、已核验结论（事实/计算/推论，带引用数），完成后可导出 Markdown / PDF 报告。

## 三、演示脚本（5 分钟）

1. **开场**（30s）：一句话定位——「链眼把一份年报变成一条可追溯的投研闭环」。
2. **数据复核**（1min）：上传宁德时代年报 → 展示 15 条候选事实 → 复核一条「收入」并点开原文证据，强调「每个数字都能回到 PDF 原文」。
3. **财务诊断**（30s）：切到「财务诊断」，看 2024 vs 2025 收入/毛利率对比。
4. **情景研究**（1min）：设 s=1、x=-0.1、k=0.5 运行情景，展示毛利率变化；再跑 27 格点敏感性。
5. **研究任务**（1.5min）：输入研究问题 → 展示智能体自动编排的节点流转 → 生成 3 条带引用的结论 → 导出 Markdown 报告。
6. **收尾**（30s）：强调「事实-计算-推论三层分离 + 全链路溯源 + 可复现」三个竞赛核心点。

## 四、可追溯与可复现

- **可追溯**：每个数字、每条结论都能回到原始 PDF 页 / 计算过程 / 假设，SHA256 锁定原始文件。
- **可复现**：同一份数据 + 同一假设，结果确定；报告绑定数据快照版本，不随后续修改静默变化。
