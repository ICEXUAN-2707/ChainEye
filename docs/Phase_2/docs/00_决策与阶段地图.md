# 决策与阶段地图

## 目标与边界
用户上传新能源电池企业财报，系统识别企业/年度，提取可复核事实，开展行业化财务分析与显式假设情景，形成有依据、反证、限制和跟踪条件的研究建议。
新能源广域作为产品愿景，当前验证范围是电池制造企业；光伏、风电、整车不共用电池情景模型。首版不微调大模型，不建设复杂知识图谱，不强制迁移现有技术栈。

## Agent 与交付决策

采用现有单体后端、SQLite 单 worker 和 Run 体系上的自有 typed graph，不新增平行编排系统，也不为了角色数量堆叠“多 Agent”。内部 Agent 复用全部六个白名单 Tool；MCP MVP 仅以 stdio 暴露受控只读资源和工具。Prompt、Skill、Tool 和 graph 必须有可记录的 ID、版本和内容哈希，最终 trace 可连接 `Run → Node → Skill → Tool → Prompt → Output`。

本阶段不做 Docker/Compose，原生复现目标为 Windows 11 与 Ubuntu。live 调用使用真实 DeepSeek 配置；replay 只能来自真实保存 Run，并显式标注为回放。

## 待实测决定
第二家企业、OCR引擎/模型版本、检索与重排引擎、DeepSeek具体模型能力、耗时内存预算均待P2.0核查/POC。Codex有权在已冻结目标内提出并记录合理实现选择；只有扩大范围或改变金融含义需团队共同决策。
已有第二家样本优先复用；否则从亿纬锂能、国轩高科中依官方披露完整度选择一家。它们是待调研候选，不代表已验证财报或同口径数据可得。
