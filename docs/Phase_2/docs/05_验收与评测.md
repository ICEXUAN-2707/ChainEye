# 验收与评测计划
所有数值是未来验收目标，不是当前结果。先建立标注和分母，再运行；保留原始输出，不用人工修改后结果抬高准确率。

## 数据集与统计
保留宁德时代回归集；选择第二家电池企业：一份年报可用于适配，另一未参与调试的材料留作迁移测试。若仅一份，按页冻结held-out并明确不是跨报告泛化。
POC20页/≥60字段用于选型；最终独立测试≥20页/≥60字段，包含真实扫描表格且两公司都有样本。保存来源、hash、页号、split、人工答案、允许显示舍入规则；测试答案不传给模型。
字段联合准确率=正确值+单位+期间+业务/范围的字段数/全部必需标注字段；漏提和错列算错。覆盖率=返回候选的必需字段数/必需字段数。报告按企业/扫描与原生/指标类别拆分；不存在字段列缺口，不编造分母。

## 发布阻断
错误金额或口径、伪造证据、跨企业污染、未复核伪verified、不可恢复版本覆盖、泄露密钥、关键主流程阻断必须修复。正常数据缺口可明确partial，但两家公司核心验证闭环不能缺失。
