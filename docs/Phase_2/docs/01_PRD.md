# 第二阶段PRD

## 用户与价值
目标用户是研究新能源电池行业的学生、分析人员和团队。核心问题：企业增长是否创造真实盈利与现金？投资扩张是否带来资金压力？业务结构及产业链变化如何影响经营？证据够不够支持建议？
成功表现为另一家企业财报也能运行，而不是固定宁德时代报告模板替换公司名。

## 核心用户流程
上传财报→识别企业/年度待确认→解析进度与警告→候选事实与原文复核→查看模块可用性→选择研究问题和假设→执行研究→查看结论/反证/缺口→导出。
企业身份不确定时停止事实归属与公司结论；可先解析页面。用户选择与文档识别冲突时提示核对，不能静默重命名文档。

## 五模块
M1 盈利增长：同口径收入同比、毛利润、毛利率及业务贡献。
M2 现金营运：经营现金流、利润对照、存货/应收变动、减值附注。分子分母口径差异须披露，不用余额变动直接推断周转率。
M3 扩张资金：资本开支、在建工程、投资现金流、负债及现金状况；资本开支与投资现金流不是同一个指标，不缺省代替。
M4 行业竞争：动力/储能结构、研发、海外业务、客户集中度、风险因素；仅对披露足够的维度分析。
M5 产业链情景：已复核业务收入/成本+用户s/x/k静态假设；现有公式与范围保持。没有同口径业务数据则unsupported或missing_data。
五模块均有明确状态；至少M1/M2/M5在两家验证企业具备可执行材料，M3/M4不足维度标partial并给补充材料需求。原件不披露的内容不计为提取器漏检，也不自动豁免必需验证流程。

## 页面
P1 数据入口：从固定公司下拉升级为数据包/企业选择与识别确认。
P2 解析复核：逐页来源类型、进度、OCR标识、警告、事实表和原件联动。失败页不会显示空白成功。
P3 研究工作台：五模块状态、研究问题、假设确认、结果和证据。
P4 建议/报告：事实、计算、假设、推论分开；每条建议展示条件与跟踪指标，缺证据可见。
各页面包含加载、空、失败、需复核、partial、stale；真实运行与回放明确标识。

## 不纳入P0
任意行业全覆盖、自动买卖评级与目标价、微调、多Agent角色数量扩张、整本年报无人工介入全自动正确、公司不披露的真实产能/传导参数、无连续价格的回测。
