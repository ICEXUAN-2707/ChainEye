# 给Claude的启动指令

你负责链眼第二阶段frontend与交互。在现有仓库读取AGENTS/README和`docs/Phase_2/`文档；先复现当前页面与构建，列已实现/缺失，保留既有成果。
共用后端生成OpenAPI及TypeScript，不另写Fact/Report。接口未实现可开发标识mock，但交付需真实联调。公司数据不能在前端用姓名替换CATL结果；金额字符串保持，不以浮点提交。

按develop的已合并契约建立短期任务分支：
1. 企业识别/候选确认、冲突提示、数据包版本更新与切换。
2. 作业/页状态、OCR标识、原页与事实联动、失败重试、人工复核与409冲突。
3. 五模块能力状态、研究问题与假设、partial/stale结果、证据与计算卡片。
4. 建议卡片（依据/条件/跟踪/限制）、JSON/Markdown报告入口与真实/回放标识。
前端展示的高亮必须使用后端真实坐标映射，缺bbox时页级显示。轮询/取消请求不要让旧数据包响应覆盖当前视图。

每块交付构建、桌面与390窄屏截图、加载/空/失败/部分成功/需复核/过期状态清单及真实接口结果。互审后端一个来源→事实→证据流程。契约不足提出场景/请求/期望响应，由双方共同更新。
不能宣称所有企业都支持专项模型；企业读取和研究可用性分别展示。最终在自己电脑从干净clone完成完整流程并记录。
