2026-10-01 R2提取与复核后端：保持既有SourceAttachment、FactCorrection和Fact静态形状，启用同步PyMuPDF文本层解析、限定宁德时代2024/2025年报版式的确定性字段提取、真实PDF页码/bbox证据及PATCH复核。提取要求年份、表头、行名、千元单位和合并范围上下文；扫描件及不支持材料不猜测。更正事务原子写Fact新revision、Dataset新版本和更正日志，并校验证据属于当前数据包版本；旧revision和快照保持可读。OpenAPI仅更新能力说明，生成TypeScript类型无形状变化。R3及以后能力未提前实现。

2026-10-02 R2合并后维护：不改变领域或HTTP契约。将提取与人工复核共用的Decimal规范字符串格式化收敛到domain单一实现；测试客户端及本地HTTP冒烟从已被Starlette弃用的httpx迁移到锁定的httpx2 2.13.0，并补齐httpcore2/truststore锁定依赖。宁德时代及2024/2025限定仍是当前R2明确边界，未提前扩展为通用年报解析。

2026-10-03 R3财务与情景后端：不新增路由或DTO，启用既有POST /scenarios与GET /calculations/{id}。新增六项确定性财务指标规则；情景严格绑定dataset/version与Fact revision，只接受同公司、同业务、同年度、同币种、同报表范围的verified动力电池或储能收入/成本。Scenario、9条Calculation与dataset范围幂等记录单事务写入，规范JSON哈希相同请求复用、不同请求409，记录至少保留24小时。旧快照和旧计算不随事实更正改变；27组演示网格为确定性条件计算，不解释为预测或置信区间。Run、Agent、报告与价格历史能力仍未实现。

2026-10-03 R3回溯加固：不改变HTTP/领域契约。修复时点指标跨期比较只校验连续年份、未校验相同月日的问题；存货和应收变化现要求可比时点。增加三类口径独立金值、两业务真实基线54组情景、证据归属、错误零写入、9条Calculation完整快照、24小时幂等、跨dataset key隔离、8路并发及事务回滚测试。全量94项测试通过；人工第二复核和财务签核仍待实际人员完成。

2026-10-04 R4 Agent与证据后端：不新增或改变冻结HTTP DTO，启用Run创建、状态读取、事件游标和waiting_review恢复。Run请求及模型/Prompt版本落库，dataset范围幂等至少24小时；单worker从SQLite原子领取任务，启动时只自动恢复安全节点。编排严格限制为六个白名单工具，工具调用记录输入输出限额与哈希；所有财务和情景结果继续走R3确定性服务。DeepSeek适配器使用固定官方端点，密钥只从环境读取；无密钥、超时/429及无效JSON不会显示成功。回放要求同owner同快照并且不调用模型。R4结束于已校验Claim，报告接口继续501。真实付费API三次验收仍需团队提供密钥后执行，不能由Fake适配器结果替代。

2026-10-04 R4 二次加固：不改变 HTTP DTO、数据库表或 R5 边界。修复反证与模型未见引用的范围校验、不可变快照缺事实的错误恢复、情景结果未进入 Claim、空模型结果假成功及工具/LLM 端口偏差；数字 Claim 增加引用对象精确对照，不支持数字降为 `insufficient`。真实 DeepSeek 在临时数据上完成三次端到端调用，均返回模型 ID、usage、latency 和 request_id 并完成 Run；供应商未直接返回费用字段，账单核对仍为人工项。

2026-10-05 R5后端报告：不新增路由、DTO或数据库表，启用既有GET /runs/{id}/report及Report记录。ReportService按冻结接口从Run快照、Claim和Calculation组装报告，逐一校验Fact revision、Scenario、Evidence、Calculation和Assumption引用；JSON、Markdown和PDF均基于同一持久化Report。Run完成态、报告写入和report_generated事件单事务提交，未完成Run返回409 REPORT_NOT_READY；证据不足或非法引用Claim不进入正文且在limitations披露。API说明版本提升为0.4.0，静态DTO形状不变。未增加OCR、通用年报提取、价格预测、部署或其他R6能力。
