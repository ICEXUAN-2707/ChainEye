# HTTP接口契约 v0.2

权威来源是backend路由/DTO/领域模型；contracts/openapi.json由tools/export_contracts.py生成。所有JSON请求禁止额外字段。错误统一为{"error":ErrorBody}，含request_id、retryable和details。金额和情景参数必须十进制字符串，禁止JSON浮点数。
下表所有领域路径有 `/api/v1` 前缀；共16操作，另有GET /health。

|方法与路径|请求|响应|R1状态|
|---|---|---|---|
|POST /datasets|DatasetCreate|201 Dataset|持久化创建空数据包|
|GET /datasets|offset/limit|DatasetCollection|可用|
|GET /datasets/{id}|version可选，省略只用于读取最新元数据|Dataset|可用|
|POST /datasets/{id}/sources|multipart file/url?/published_date?|201 SourceAttachment：提取后的最新Dataset+独立Source|R2可用|
|GET /datasets/{id}/facts|version必填；status/segment可选|FactCollection|可用；不存在快照404|
|PATCH /facts/{id}|FactCorrection|Fact|R2可用|
|POST /runs|RunCreate，Idempotency-Key必填|202 Run|R4，501|
|GET /runs/{id}|无|Run|已有记录读取；R1不创建Run|
|GET /runs/{id}/events|after_seq/limit|EventCollection|已有记录读取；R1无真实事件|
|POST /runs/{id}/resume|ResumeRequest|202 Run|R4，501；不存在Run404|
|POST /scenarios|ScenarioRequest，Idempotency-Key必填|201 ScenarioResult|R3可用；精确快照校验与24小时幂等|
|GET /evidence/{id}|无|Evidence|样本可用|
|GET /calculations/{id}|无|Calculation|可用；R3情景创建可追溯计算记录|
|GET /sources/{id}|无|Source|样本可用|
|GET /sources/{id}/content|无|PDF/CSV文件|样本PDF可用；读前复核SHA256|
|GET /runs/{id}/report|format=json/markdown/pdf|Report或文件|R5，501；不存在Run404|

上传接收最大30 MiB、500页的未加密PDF；每个数据包最多关联5个来源。后端按实际签名和PDF结构校验，不信任扩展名或声明MIME。内容以SHA256去重：同一数据包重复上传返回原Source且不增加版本；跨数据包复用Source但为目标数据包创建新版本。上传后同步运行文本层确定性提取，支持的宁德时代2024/2025版式进入`parsed`并写候选事实；扫描件、不支持的公司/年份/版式或字段上下文不完整时为`needs_review`，不启用OCR或LLM。候选只允许`extracted`、`missing`或`conflict`，绝不自动写`verified`。来源关联和新增候选可各产生一个不可变版本，调用方只使用响应中的最终`dataset.version`。完整参数、必填字段及静态Schema以OpenAPI为准；其他占位接口不会写入成功记录。501 NOT_IMPLEMENTED与运行失败不同，前端必须展示尚待实现。

FactCorrection不能更改metric、segment、期间：口径错误创建新Fact并使旧记录失效；值更正带expected_revision和reason，事务生成新revision及Dataset版本。missing须null+reason；verified须证据。raw_value若省略由程序反算并记录人工更正，禁止伪装自动提取。R2须验证证据的数据包归属。
ScenarioRequest收入/成本Fact须属于显式dataset版本，revision一致且为verified。服务查库验证、执行纯Decimal内核，并在同一事务中落库Scenario、9条Calculation及幂等响应；客户端不提交结果。当前只支持动力电池和储能业务固定销量、业务结构及其他投入的条件情景，不是预测或置信区间。
Report引用AssumptionRecord.id以连接Claim假设引用；数字由程序模板插入。模型文字须经引用与支持性检查。
API金额为人民币元；显示亿元除1e8，ratio显示百分数乘100，pp不再乘100。前端只格式化，不承担权威计算。
Source独立于Dataset，文件身份可复用，关联由dataset_sources记录；版本在SourceAttachment.dataset返回，不能把数据包版本塞进Source。

R1为local-only，绑定loopback并检查client/host/origin，没有公网登录。R6实现后端session cookie（HttpOnly、SameSite、公网Secure）与owner授权；禁止直接公开本地模式。模型key永不进前端。
Schema只能验证静态形状，不能证明归属、权限、快照、引用支持和业务口径；这些动态约束必须在application实现并测试。
