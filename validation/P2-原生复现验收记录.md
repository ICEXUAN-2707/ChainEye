## 本轮交付

- `chain_eye.observability` 输出有界 UTF-8 JSONL，固定包含 timestamp、level、request/run/node/skill/tool/prompt/model、耗时、状态与错误码字段。
- 敏感键及 Bearer、`sk-*`、key/token/secret/password 赋值模式递归脱敏；不使用未知对象 repr，不记录完整环境、请求头、二进制正文或无界文本；单行上限 64 KiB。
- HTTP、Agent node、Tool 调用和 Run 结束状态接入同一日志边界；不改变 HTTP/OpenAPI DTO、数据库迁移、金额或复核语义。
- `preflight.py` 只读检查 Python 3.12、Node 24、UTF-8、npm、锁文件、依赖状态、目录和端口；未安装项目依赖给 warning，由 `bootstrap.py` 按锁文件安装。
- `start_all.py` 监督 API/Vite、核对实例 nonce、拒绝端口占用和无密钥 `--live-model`；普通模式移除凭据类环境变量并禁止模型，退出后清理进程并写 `stopped`。
- `reproduce_core_flow.py --mode replay` 在隔离 SQLite 中保存一个真实 no-paid live Run，再回放该终止 Run；不使用 fixture LLM 冒充真实模型成功。
- `export_run_trace.py` 经 MCP 同一只读 Tool/字段白名单和脱敏边界分页导出；同一 Run 重复导出字节稳定。
- CI 矩阵固定 Python 3.12、Node 24、UTF-8，并在 Ubuntu/Windows 执行测试、契约、前端、preflight、依赖闭包、replay、MCP、受监督启动和 HTTP smoke。

## 失败与修复记录

1. 第一次定向测试未设置 `PYTHONPATH=backend/src`，4 个模块导入失败，未执行测试；补齐仓库规定环境后重跑。
2. 第一次全量回归在整个测试进程设置 `CHAIN_EYE_DISABLE_MODEL=1`，导致 4 个 mock DeepSeek HTTP 边界测试在请求前返回 `MODEL_UNAVAILABLE`；结果为 197 项、4 error、153.888 秒，不能记为成功。修复为只在 replay/MCP/HTTP smoke 子进程中硬禁模型，mock 边界测试恢复，最终全量通过。
3. 交叉审阅发现 `start_all --verify-only` 最初残留 ready 状态、显式 live 未强制密钥、trace manifest 含导出时间导致重复哈希变化；均已修复并增加回归测试。
